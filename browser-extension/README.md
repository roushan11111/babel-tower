# 巴别塔 · 浏览器扩展

连接本机巴别塔增强版，在 Chrome / Edge 中使用网页翻译和输入框旁的“译”。作者：[@HanJaKKK](https://x.com/HanJaKKK)，MIT 许可。

## 安装与配对

1. 运行巴别塔 0.2.0 或更新版，在小窗口开启浏览器连接并复制配对码。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”，选择本文件夹 `browser-extension`。这个项目不会自行修改浏览器设置或安装扩展。
4. 打开扩展“详情”里的“扩展程序选项”，粘贴配对码，点击“保存并检查连接”。看到“已连接本机巴别塔”即可。
5. 刷新已经打开的普通网页；可将巴别塔固定到浏览器工具栏。

配对码只保存在当前浏览器的扩展本地设置中，不会放入网页，也不会同步到云端。重新生成配对码后需要重新配对。已有连接时，配对码留空可保留已保存的配对码。

## 使用

- **一键翻译网页**：点击工具栏的巴别塔，再点“一键翻译当前网页”。文字在原有网页位置显示，链接和原有事件保持。点击“还原原文”恢复；“停止翻译”中止剩余任务。
- **输入框“译”**：点击输入框，写完一句话，再点右边的“译”。扩展只读取这一框的整句，把译文放回原输入框，不点击发送。如果翻译期间修改草稿或切换输入框，结果会放弃写入。
- **选择语言**：方向跟随巴别塔小窗口。扩展菜单和设置页也可修改，点击“保存翻译方向”同步生效。可用语言从本机程序读取。
- **关闭输入按钮**：扩展设置中取消“在网页输入框右边显示‘译’”，保存即可。

网页翻译按独立文字节点处理，不把模型结果当成 HTML。每批最多 4 条、不超过 4000 字，每页最多 600 个节点、120000 字；超过上限或单个节点超过 4000 字会跳过。较长网页会逐步翻译，可随时停止。网页自行更新、页面滚动加载新段落后，需要再次点击翻译；还原时会保留网页在翻译后自行改过的文字。

每个翻译请求等待最多 25 秒。首次加载本地模型时可能超时，请先启动巴别塔并等待模型预热，或减少文字后重试；未完成的原文和草稿会保留。停止和超时只终止扩展的等待与写回，本地模型可能仍继续完成当前运算。

## 范围与限制

支持普通 HTTP/HTTPS 网页顶层正文，以及可编辑的文本输入框、textarea 和部分 contenteditable 编辑器。代码、导航菜单、表单、隐藏文字、`translate="no"` 标记和明确同目标语言的段落会跳过。输入框功能会排除密码、验证码、邮箱、数字输入、只读/禁用框、含锁定对象的编辑器等；网站可为敏感内容加 `data-babel-protected` 标记。

浏览器内部页、Chrome/Edge 扩展商店、PDF、图片文字、iframe、封闭 Shadow DOM 和一些复杂网站编辑器暂不支持。部分网站可能重新渲染并恢复自己的内容。输入框替换需编辑器接受标准 input 事件；contenteditable 使用浏览器文本编辑命令保留撤销记录，不能接受时不会使用破坏结构的 HTML 替换。安装并不代表所有网站已验证。

扩展不读取剪贴板，也不请求云端翻译。配对后的请求仅由扩展后台发往固定的 `http://127.0.0.1:17863`，要求 `X-Babel-Token`，拒绝重定向。正常网页本身无法修改方向或取得配对码。

## 权限与本地接口

- `storage`：保存本机配对码和输入按钮开关，仅可信扩展上下文可读。
- `activeTab`：用户打开工具栏菜单时操作当前页。
- 内容脚本匹配普通 HTTP/HTTPS 网页：用于输入框旁持续出现的“译”，浏览器可能提示可读取和修改网站数据。正文或草稿只有在用户主动点击相应翻译动作后才发送到本机。
- `http://127.0.0.1/*` 主机权限：Chrome 匹配规则不能限定端口；实际地址在代码与扩展安全策略中固定为 17863。
- 无剪贴板、历史、截图、原生消息、任意云端主机权限。

请求均需配对码：

| 接口 | 作用 |
| --- | --- |
| `GET /v1/status` | 读取源语言、目标语言和可用语言列表 |
| `POST /v1/settings` | 只保存 `{sourceLanguage,targetLanguage}` |
| `POST /v1/translate` | 提交 `{text,sourceLanguage,targetLanguage}`，读取 `{text,...}` |

参考浏览器官方说明：[内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[扩展网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[消息传递](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)、[本地存储访问限制](https://developer.chrome.com/docs/extensions/reference/api/storage)、[MV3 服务线程生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。

## 验证记录

开发验证使用独立的无界面 Edge（Chromium）测试配置、真实 Manifest V3 服务线程和内容脚本，配合只含合成文字的本机模拟桥接接口。45 项检查通过，覆盖正文/输入框替换、保留链接事件、还原、SPA、取消、迟到译文、草稿变更、敏感字段、maxlength、beforeinput 拒绝、React 风格输入事件、contenteditable、语言同步和配对码隔离；还实际验证了 25 秒等待超时、4 条批次上限，以及 beforeinput 处理器移焦点、开启输入法组合或修改后还原草稿时不写入、不抢焦点。

模拟桥接测试验证扩展集成和保护逻辑，不能代表模型翻译质量或真实网站兼容性。没有操作用户的浏览器配置或聊天页面。
